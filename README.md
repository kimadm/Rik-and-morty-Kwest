# Rik-and-morty-Kwest

Полноценный анимированный квест в духе абсурдной sci-fi комедии: исследование сцен, диалоги, инвентарь, шкала хаоса, несколько концовок и простые 2D-анимации персонажей.

## Цель первой версии

Собрать рабочий MVP, который проходится от главного меню до одной из концовок:

1. Главное меню
2. Гараж Рика
3. Чёрный рынок измерений
4. Планета живых инструкций
5. Бюрократическое измерение
6. Финальный гараж
7. Инвентарь
8. Шкала хаоса
9. Диалоги с выбором
10. Минимум 4 концовки
11. Сохранение в LocalStorage
12. Заглушки анимаций персонажей и портала

## Рекомендуемый стек

- Vite
- React
- TypeScript
- Phaser 3

## Документы

## Важное замечание по правам

Для личного фанатского прототипа можно использовать узнаваемые образы. Для публичного или коммерческого релиза нужно заменить персонажей, названия, визуальные образы, музыку и реплики на оригинальные пародийные аналоги.

## Local development

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually `http://localhost:5173/`.

Create a production build with:

```bash
npm run build
```
